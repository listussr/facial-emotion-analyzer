# `emotion_moments` — моменты, требующие внимания

Детерминированная основа агента-аналитика ([AGENT.md](../AGENT.md)): секундный ряд эмоций субъекта, детекторы
кандидатов, их слияние в моменты, значимость и обзор сессии. От MCP и LLM модуль не зависит: им пользуются
MCP-сервер, отчёт и командная строка.

```
src/emotion_moments/
├── series.py      EmotionSeries (series.json → numpy), jsd, LABELS_RU
├── detectors.py   четыре детектора (устойчивость — для каждой эмоции профиля), Candidate
├── moments.py     find_candidates, merge_candidates, detect_moments, значимость, TYPE_TITLES
├── overview.py    session_overview, quality_flags
├── profile.py     Profile, load_profile (profiles/<name>.yaml)
└── __main__.py    python -m src.emotion_moments — кандидаты в терминале
profiles/interview.yaml   профиль «структурированное интервью»
```

---

## Ряд (`series.json` → `EmotionSeries`)

`series.json` пишет архиватор (см. [session_archive.md](session_archive.md#секундный-ряд-seriesjson)). В
`EmotionSeries` строки — секунды, NaN — нет данных:

| Поле | Смысл |
|---|---|
| `fused`, `face`, `voice` | N × 6 вероятностей: итог, только лицо, только голос |
| `face_present` | доля кадров секунды с лицом субъекта |
| `predicted` | доля из них, где рамку предсказал трекер (штатно около 0.5: детектор раз в 2 кадра) |
| `others` | доля кадров с другими людьми |
| `speech` | доля кадров с речью |

`jsd(p, q)` — расстояние Дженсена — Шеннона по основанию 2: 0 — распределения совпадают, 1 — не пересекаются.

## Детекторы

| Тип | Функция | Правило |
|---|---|---|
| `sustained_anger`, `sustained_sadness` | `detect_sustained` | вероятность ≥ `enter_p` дольше `min_duration_s`; гистерезис: интервал держится, пока ≥ `enter_p − exit_delta`; провалы данных до `max_gap_s` не рвут |
| `abrupt_change` | `detect_abrupt_changes` | средние распределения за `window_s` до и после секунды: JSD ≥ `min_jsd`, ведущая эмоция сменилась, новая ≥ `min_new_p`; из соседних (`suppress_s`) остаётся сильнейшая |
| `face_voice_divergence` | `detect_face_voice_divergence` | при речи (`min_speech`) ведущие эмоции лица и голоса разные, обе ≥ `min_p`, JSD ≥ `min_jsd` — дольше `min_duration_s` |
| `flat_affect` | `detect_flat_affect` | в окнах `window_s` (шаг — половина окна) средний JSD секунд до среднего по окну ≤ `max_variability`; соседние окна сливаются |

Каждый кандидат (`Candidate`) несёт:
- интервал;
- **интенсивность** — для устойчивости средняя вероятность, для смены и расхождения расстояние;
- **уверенность** — доля секунд с данными, сниженная, если трекер предсказывал рамки чаще штатных 50%;
- метрики, включая качество интервала (лицо, трекер, речь);
- параметры, с которыми он найден.

## Моменты и значимость

- `find_candidates` запускает детекторы, включённые в профиль.
- `merge_candidates` сливает кандидаты, которые пересекаются или разделены не больше `merge_gap_s`. Например,
  резкая смена, переходящая в устойчивый гнев, — один момент с двумя типами. Id моментов `m1, m2, …` идут
  по времени.
- **Значимость кандидата** = вес типа × интенсивность × уверенность × множитель длительности. Множитель растёт
  от 0.5 до 1 к `ref_duration_s`, у резкой смены он равен 1.
- **Значимость момента** — максимум по его кандидатам плюс `extra_type_bonus` за каждый дополнительный тип.
- **Уровень** — `high`, `medium` или `low` по `significance.levels`.
- `detect_moments` возвращает моменты от самого значимого.

## Профиль сценария

`profiles/<name>.yaml` содержит:
- пороги детекторов и веса;
- `merge_gap_s` и параметры значимости;
- `prompt_notes` — что сказать модели о сценарии.

Каталог задаёт `AGENT_PROFILES_DIR`. Первый профиль — `interview`: интервью одного человека. Числа в нём
предварительные. На текущих тестовых записях (фрагменты фильмов по 15–57 с) детекторы находят мало моментов,
поэтому пороги подбираются на записях нужного сценария.

## Обзор сессии

`session_overview` возвращает:
- длительность, доли времени с лицом и с речью;
- по модальностям — средние вероятности и доли секунд с каждой ведущей эмоцией;
- флаги качества: `low_face` (лицо меньше 60% времени), `many_predicted` (трекер больше 75% рамок),
  `others_in_frame` (другие люди больше 20% времени), `no_voice` (нет оценок голоса).
