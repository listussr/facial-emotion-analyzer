# `face_detection` — детекция лиц

Найти лица на кадре и вернуть рамки `[x, y, w, h, conf]` в координатах исходного кадра.

```
src/frames_processing/processing/face_detection/
├── face_detection.py  YuNetFaceDetector, MediaPipeFaceDetector, фабрика FaceDetector, geometry_post_filter
└── filters.py         fast_face_filter, pass_face_filters: эвристики «похоже ли на лицо»
```

---

## Фабрика

```python
detector = FaceDetector(min_detection_confidence=0.6, backend="yunet", max_side=480)
detections = detector.detect(frame_bgr)   # [[x, y, w, h, conf], ...]
```

`backend` — `yunet` (по умолчанию) или `mediapipe`; остальные аргументы передаются конструктору детектора.
В видеопайплайне детектор выбирается переменными `DETECTOR_BACKEND`, `DETECTOR_MIN_CONF`, `DETECTOR_MAX_SIDE`.
Веб-сервер использует тот же детектор для поиска человека по фото.

## `YuNetFaceDetector`

- `cv2.FaceDetectorYN` с моделью `models/crema/face_detection_yunet_2023mar.onnx`.
- **Почему YuNet:** на его рамках обучалась модель эмоций CREMA-D. Тот же детектор при инференсе даёт
  те же кропы, что и при обучении.
- Кадр уменьшается до `max_side` по длинной стороне. 480 — масштаб видео CREMA-D и вдвое дешевле 640;
  для мелких лиц на широком кадре значение стоит увеличить.
- Размер входа детектора меняется только при смене размера кадра.
- Рамки масштабируются обратно, обрезаются по краям кадра и проходят `geometry_post_filter`.

## `MediaPipeFaceDetector`

Прежний детектор по умолчанию, оставлен для сравнения. Кадр уменьшается в `scale` раз, рамки фильтруются
так же.

## Фильтры

**`geometry_post_filter(height, width, frame_height, frame_width)`** отсекает рамки:

| Условие | Отсекается |
|---|---|
| сторона меньше 40 пикселей | слишком мелкое лицо для модели эмоций |
| высота / ширина вне 0.75–1.7 | не лицо по пропорциям |
| площадь меньше 0.2 % или больше 50 % кадра | шум или «лицо на весь кадр» |

**`fast_face_filter(gray, width, height)`** — дешёвая проверка по градиентам: слишком ровная область
(стена, ткань) — не лицо. Видеопайплайн вызывает её один раз на трек, на первой свежей детекции после трёх
попаданий, и кэширует результат.

**`pass_face_filters`** — более строгая проверка голосованием 2 из 3: горизонтальные градиенты верхней части
(брови, глаза), контраст центра против краёв, симметрия. Сейчас в пайплайне не используется.

## Неочевидное

- Детектор работает раз в `DETECTION_FREQUENCY` кадров (по умолчанию 2). Между детекциями рамки
  предсказывает трекер, поэтому стоимость детекции делится на N.
- `cv2.setNumThreads(1)`: лишние потоки OpenCV почти не ускоряют YuNet на кадре 480 пикселей, но заметно
  увеличивают общую нагрузку на CPU.
